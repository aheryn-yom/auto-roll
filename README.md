# AutoRoll

无 Root Android 自动滑屏工具，面向漫画、小说和长页面阅读。首版提供间歇上滑与微滑动近似连续滚动，两种模式共用一个悬浮控制点。

## 兼容性

- Android 8.0（API 26）及以上
- 使用 Android 17（API 37）SDK 编译并以 API 37 为目标
- 手势坐标依据当前屏幕尺寸计算；悬浮尺寸使用 dp，适配 2608×1200 等高分辨率屏幕和显示密度变化
- 悬浮控制器由无障碍服务创建，不请求 `SYSTEM_ALERT_WINDOW`
- 构建要求：JDK 17、Gradle 9.9.1、Android Gradle Plugin 9.5

## 使用

1. 安装并打开应用。
2. 点击“开启无障碍服务”，在系统设置中启用“自动滑屏控制”。
3. 返回阅读应用；屏幕右侧会显示可拖动的小白点。
4. 拖动速度滑动条连续调节速率（0.1% 精度，慢/中/快为参考刻度），再点击“间歇”或“连续”开始。
5. 运行中点击小白点停止；长按约半秒可拖动位置。
6. 在系统无障碍设置中关闭服务即可移除控制器并停止滑动。

无障碍服务只声明手势能力，不请求读取活动窗口内容；不采集或上传数据。Android 与各厂商系统可能会限制后台服务存活，MIUI/HyperOS 也可能需要用户在应用信息中允许自启动或后台运行。

## 模式说明

- **间歇**：每次执行较长上滑，等待页面惯性滚动后再继续，适合漫画及常规阅读器。
- **连续**：重复短距离微滑动近似连续滚动。滚动步长与惯性由目标阅读器决定，不能保证恒定像素速度；分页阅读器可能需要点击翻页，当前版本不覆盖。

悬浮控制点为半透明深灰小点；设置菜单保持不透明以确保文字清晰。点按控制点用于开关菜单或停止，按住约半秒后拖动可调整位置。屏幕方向改变后手势会重新读取当前尺寸。

停止会立即取消后续手势调度；如果系统正在执行当前一段触摸轨迹，该段可能完成后才结束。

## 构建

需要 JDK 17、Android SDK Platform 37 和 Android SDK Build-Tools 37。

```bash
./gradlew assembleDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`
